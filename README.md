# Vehicle Inspection Platform

This repository contains the frontend application for an Automobile Inspection Platform. It empowers auto businesses and inspectors to digitize their workflow, track vehicle conditions, and generate professional reports.

## 🚀 Key Features

*   **Digital Inspections:** Easily conduct and record new vehicle inspections via the new inspection interface.
*   **Comprehensive History:** Track and search through past inspections in a centralized dashboard.
*   **Report Generation:** Preview and generate detailed condition reports for clients or internal records.
*   **Company Management:** Manage company profiles, user onboarding, and account settings directly from the application.

## 🏗️ Project Structure

- **`frontend/`**: The React application that provides the user interface for conducting and managing automobile inspections.

## 🛠️ Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Frontend Setup
1. Navigate to the `frontend` directory: `cd frontend`
2. Install dependencies: `npm install` (or `yarn install`)
3. Start the development server: `npm run dev` (or `yarn start`)
